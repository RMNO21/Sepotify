# Contributing to Sepotify

Thank you for your interest in improving Sepotify!

## Development Workflow
1. Fork the repository and create your feature branch:
   `git checkout -b feature/audio-improvement`
2. Follow Android Kotlin coding standards and ktlint styling.
3. Test audio playback thoroughly on both emulators and physical devices.
4. Submit a Pull Request with a clear description of changes.

## Bug Reports & Feature Requests
Please use the GitHub Issue Tracker to report bugs or submit feature proposals.
